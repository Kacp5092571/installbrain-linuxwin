# .exe- File naming system 
e.g. brain-3.0betap1.exe  \
3.0beta - 3rd beta edition, p1 = patch 1. (m on the end means added metadata

# Installation Process (for people with bad tech understanding)
1. Click on your desired OS  \
2. Click on the file you would like to download  \
3. Press "View raw"  \
4. Choose your installation path and press OK  \

# Troubleshooting
If the file will not open, press "Open anyways" on Windows or  \
run as Administrator. If it still won't run, use cd in the terminal to   \
open the folder where the .exe file is and then type its full name in (including .exe on Linux   /
but unecessary on Windows)  \
If it still doesn't work, check if you chose the right OS. (e.g. Linux version on Windows cannot work)
If there are any other problems, report it in the community :D
